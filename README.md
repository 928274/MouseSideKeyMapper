# 鼠标侧键映射（MouseSideKeyMapper）

一个纯托盘的 Windows 鼠标侧键映射工具：把鼠标上/下侧键映射为任意按键组合或系统命令。
纯 C#5 + WinForms，无第三方依赖，`build.bat` 一条命令编译出可执行程序。

---

## 功能特性

- **上侧键 / 下侧键可独立映射**为按键组合或系统命令
- **纯托盘运行**：无任务栏窗口、无任务栏按钮，隐藏窗口常驻
- **多套配置一键切换**：扫描 exe 同目录所有 `*.ini`，托盘二级菜单勾选切换
- **记住上次配置**：重启自动加载上次使用的 ini（`lastconfig.txt`）
- **单实例**：重复启动自动提示并退出
- **高 DPI 感知**：托盘菜单文字清晰不模糊
- **开机自启**：以管理员权限开机自动运行（任务计划方式，详见下文）
- **注：程序以管理员权限运行**（manifest `requireAdministrator`），因为部分输入注入需要提权

---

## 快速开始

1. 编译出 `鼠标侧键映射.exe`（见下）
2. 双击运行（会弹 UAC 确认，以管理员运行）
3. 右侧键盘区域会出现托盘图标
   - **左键单击**：开启/关闭映射开关
   - **右键**：弹出配置菜单
4. 在 exe 同目录放好 `*.ini` 配置文件，右键托盘点「切换配置」选一个

## 配置文件（INI）

每个 `*.ini` 对应一套映射，放在 exe 同目录，文件名任意。（会显示在托盘二级菜单，“重载配置”会重新扫描INI文件）。

```ini
[Mapping]
上侧键=CTRL+C          ; 上侧键 = 复制
下侧键=CTRL+SHIFT+A    ; 下侧键 = 三键组合
```

规则：

- 编码为 **UTF-8（无 BOM）**，支持中文键名与中文注释
- 支持 `;` 行尾注释（`;` 后的内容忽略）
- 键值对写**各种命令**，见下方「命令架构」

---

## 命令架构

INI 键值对统一交给 `ExecuteCommand()` 分发，支持以下命令：

### 1. 按键组合（默认）
直接用键名，`+` 连接，支持三键：

```
上侧键=CTRL+C
下侧键=WIN+D
上侧键=CTRL+SHIFT+A
下侧键=WIN+TAB
```

**按住保持**：键名后加 `*`，按下侧键时该键**持续按住**，直到松开侧键才释放（适合需要持续按住单键的场景，如游戏里按住移动/技能键）：

```
上侧键=Z*    ; 按住上侧键期间，Z 一直保持按下
下侧键=D
```

> 注意：`*` 仅对**单个键**有效（如 `Z*`、`W*`）；组合键带 `*`（如 `CTRL+C*`）无意义。关闭映射或退出程序时会自动强制释放，防止按键卡住。

**支持键名**（不区分大小写）：

| 类别 | 键名 |
|---|---|
| 修饰键 | `CTRL` `SHIFT` `ALT`（=左键），`RCTRL` `RSHIFT` `RALT` `LWIN` `RWIN` |
| 功能键 | `F1`~`F12` |
| 常用 | `INSERT` `PRTSC` `DELETE` `HOME` `END` `PAGEUP` `PAGEDOWN` `方向键` |
| 字母/数字 | 直接写字符，如 `A` `1` |

### 2. 系统动作（无参命令词）
| 命令 | 作用 |
|---|---|
| `TASKVIEW` | 多任务视图 |
| `BRIGHT+` / `BRIGHT-` | 屏幕亮度 ±（**WMI 直调**，笔记本有效，不依赖 Fn） |
| `VOL+` / `VOL-` / `MUTE` | 音量加 / 减 / 静音 |
| `MEDIA_PLAY` `MEDIA_PAUSE` `MEDIA_NEXT` `MEDIA_PREV` `MEDIA_STOP` | 媒体控制 |
| `LOCK` | 锁屏 |

### 3. 运行程序 / 打开 / 脚本（前缀命令）
| 前缀 | 作用 | 示例 |
|---|---|---|
| `RUN:` | 运行程序，**支持参数** | `RUN:D:\工具\app.exe -config 1` |
| `OPEN:` | 按关联打开文件/网址/文件夹 | `OPEN:https://www.baidu.com` |
| `SCRIPT:` | 用解释器执行脚本 | `SCRIPT:D:\脚本\清理.ps1 -path C:\temp` |

**路径含空格用双引号包裹**，引号后是参数：

```
上侧键=RUN:"C:\Program Files\xxx\app.exe" --mode fast
```

`SCRIPT:` 按扩展名选解释器：

- `.ps1` → `powershell.exe -NoProfile -ExecutionPolicy Bypass -File`（强制执行）
- `.bat` / `.cmd` / `.vbs` / `.exe` 等 → 按系统关联执行并传参

### 4. 扩展新命令
在源码 `ExecuteCommand()` 的 `switch` 里加一个 `case` 即可：

```csharp
case "SCREENSHOT": 你的实现(); return;
```

## 托盘交互

| 操作 | 行为 |
|---|---|
| 左键单击 | 开启/关闭映射（悬停提示实时显示状态） |
| 右键 | 弹出配置菜单 |
| 菜单「切换配置」 | 二级菜单列出所有 ini，勾选当前项，单击即切换 |
| 「打开配置」 | 用记事本打开当前 ini |
| 「重载配置」 | 重新读取当前 ini + 重新扫描 ini 列表（刷新二级菜单） |
| 「开机启动」 | 开启/取消开机自启 |
| 「退出」 | 彻底释放钩子/托盘后退出 |

## 开机自启

程序以管理员权限运行（`requireAdministrator`），注册表 `Run` 启动键**无法**自动提权，因此采用**任务计划**方式：

- 创建：生成任务 XML（登录时触发 + 最高权限 + 交互令牌 + **关闭电池限制**），写入临时文件后 `schtasks /Create /XML` 导入（参照 Pavise-Game 方案）
- 校验：程序启动时自动检查任务指向路径与当前 exe 是否一致，不一致自动重建
- 效果：开机登录后**以管理员权限自动运行**，无需手动点 UAC；笔记本**用电池**也能启动

> 任务名：`MouseSideKeyMapper`

## 已知限制

| 限制 | 说明 |
|---|---|
| **系统功能键（Fn Lock 的 F5/F6 亮度等）** | 由笔记本固件/驱动硬件处理，合成键无法触发 → 调亮度请用 `BRIGHT+`/`BRIGHT-`（WMI 直调） |
| **DirectInput / Raw Input 程序**（红警2 等老游戏） | 直接读键盘设备，`keybd_event` 合成键可能不响应 |
| **`CTRL+ALT+DEL`** | 系统安全热键，无法模拟 |
| **`SendInput`** | 部分机器注入失效，故统一改用 `keybd_event` + 扫描码通道 |

├─ 鼠标侧键映射.exe     # 运行程序
├─ 默认.ini            # 配置示例（上侧键=WIN / 下侧键=任务视图）

├─ 亮度.ini            # BRIGHT+ / BRIGHT-

   ├─ Form1.cs         # 源码
   ├─ app.manifest     # 管理员 + 高DPI 清单
